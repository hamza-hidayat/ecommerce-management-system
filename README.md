🛒 ShopZone - E-Commerce Management System
A complete, full-stack e-commerce platform built for real-world retail businesses. It features a modern customer storefront and a powerful admin dashboard to manage products, orders, inventory, and sales.

🚀 Live Features
Customer Panel
Authentication: Secure Login, Register, Password Reset (JWT).
Product Browsing: Home page, product listing, live search, and detailed views.
Shopping Experience: Add to Cart, Wishlist, and product reviews/ratings.
Checkout: Shipping form with Cash on Delivery (COD) & PayPal payment options.
Order Tracking: Order history with live status tracking (Pending, Shipped, Delivered).
User Profile: Update personal info and change password.
Admin Panel
Secure Admin Portal: Separate login route strictly for admins.
Dashboard Analytics: Total sales, total orders, total customers, and low-stock alerts.
Product Management: Full CRUD (Create, Read, Update, Delete) with image uploads.
Order Management: View all orders, update statuses, and track COD payments (mark who received the cash).
Category & Review Moderation: Add/delete categories and delete inappropriate reviews.
🛠️ Tech Stack
Frontend: React, Vite, Tailwind CSS, React Router, Axios, Lucide Icons.
Backend: Django, Django REST Framework, SimpleJWT.
Database: PostgreSQL.
Emails: Console Email Backend (Easily configurable for Brevo/SendGrid).
